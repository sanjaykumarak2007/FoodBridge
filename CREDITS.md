## 💻 Technology & Platform Credits

The FoodBridge prototype is engineered using open web standards without third-party frameworks:

- **HTML5:** Semantic markup structure
- **CSS3:** Responsive layout (CSS Grid, Flexbox), custom property variables, transitions & keyframe animations
- **Vanilla JavaScript (ES6+):** Client-side dynamic rendering, form validation, and event handling
- **Web Storage API (`localStorage`):** In-browser key-value persistence for prototype demonstration
- **Web Speech API (`SpeechSynthesis`):** Simulated outdoor accessibility voice broadcast readout
